# Симуляция ладей (C++20)

Многопоточная консольная симуляция движения 4–6 ладей на шахматной доске 8×8.

Каждая ладья выполняется в отдельном рабочем потоке (`std::jthread`). Общее состояние доски защищено мьютексом, а ожидание освобождения пути и завершения пауз реализовано через условные переменные (`std::condition_variable`).

## Сборка и запуск

Для сборки требуется CMake 3.20+ и компилятор с поддержкой C++20 (`std::jthread`).

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# Запуск:
./build/rooks                         # 5 ладей на случайных позициях
./build/rooks 6                       # 6 ладей на случайных позициях
./build/rooks --seed 42 4              # указать сид и количество ладей (от 4 до 6)
./build/rooks --seed 42 A1 C3 F6 H8    # запуск с явно заданными начальными клетками
./build/rooks --help                  # справка по параметрам командной строки
```

## Правила симуляции

1. **Ходы**: Каждая ладья стремится сделать ровно 50 успешных ходов.
2. **Выбор цели**: Ладья равновероятно выбирает одну из 14 клеток по своей горизонтали или вертикали.
3. **Ожидание пути**: Если путь к цели заблокирован другой фигурой, ладья ожидает его освобождения до 5 секунд. Если за это время путь не освободился (таймаут), ладья выбирает другую цель.
4. **Пауза**: После каждого успешного хода (кроме 50-го) ладья делает случайную паузу от 200 до 300 мс.
5. **Завершение и блокировки**:
   * Ладья, завершившая 50 ходов, навсегда остаётся на своей клетке и продолжает блокировать пути другим.
   * Ладьи, которые физически больше не могут сделать ни одного хода (ни сейчас, ни после ходов соседей), помечаются как `STUCK`.
   * Симуляция завершается, когда все ладьи либо сделали по 50 ходов, либо застряли (`STUCK`).

## Структура проекта

* `include/rooks/`
  * `board.hpp` — координаты клеток, состояние доски, правила движения и алгоритм выявления тупиков (`STUCK`).
  * `simulation.hpp` — управление симуляцией, синхронизация потоков, события и тайминги.
* `src/`
  * `board.cpp` — проверка корректности ходов и распространение признака блокировки.
  * `simulation.cpp` — цикл работы потоков ладей, очереди событий и координация.
  * `main.cpp` — парсинг аргументов командной строки и вывод в консоль.
* `examples/`
  * `run-seed-42.txt` — пример полного лога симуляции.
